# موقع العثمان العقارية — Al Othman Real Estate

موقع عقاري ثابت (Static) سريع ومهيأ لمحركات البحث، مبني بـ **Astro 5** مع **GSAP + Lenis** للحركة، ولوحة إدارة عقارات بكلمة مرور على الرابط `/admin/`.

## التشغيل محليًا

```bash
npm install
npm run dev        # معاينة على http://localhost:4321
npm run build      # بناء الموقع في مجلد dist/
npm run preview    # معاينة نسخة البناء
```

## لوحة التحكم (/admin/)

لوحة عربية بكلمة مرور لإضافة العقارات وتعديلها وحذفها ورفع صورها وإضافة الأحياء. بعد كل حفظ يُعاد بناء الموقع تلقائيًا (نحو 5 ثوانٍ) ويُستبدل دون توقف.

```bash
npm install
cp .env.example .env      # ثم اكتب كلمة المرور في ADMIN_PASSWORD
npm start                 # الموقع واللوحة على http://localhost:8080 و /admin/
```

- الخادم في `server/server.mjs` (Node 20+، بدون قاعدة بيانات): يخدم مجلد `dist/`، ويطبّق تحويلات `public/_redirects`، واللوحة في `server/admin.html`.
- كل عقار ملف في `src/content/properties/`، والصور في `public/uploads/properties/`، والمدن والأحياء في `src/data/locations.json`.
- الحماية: كلمة المرور من `.env` فقط (لا تُرفع للمستودع)، جلسة 12 ساعة بكوكي HttpOnly، قفل 15 دقيقة بعد 5 محاولات خاطئة من نفس الجهاز أو 50 محاولة إجمالًا.
- **الاستضافة:** تحتاج خادمًا يشغّل Node (مثل Railway، الخطوات بالأسفل).
- عند بيع العقار: ألغِ «معروض في الموقع» فيختفي دون حذفه.

## النشر على Railway (عن طريق GitHub)

> لا يوجد `index.html` في المشروع لأنه يُبنى تلقائيًا: أمر `npm run build` يولّد كل الصفحات (ومنها `index.html`) في مجلد `dist/`، والخادم يعرضها.

1. **GitHub:** أنشئ مستودعًا خاصًا (Private) وارفع محتوى المجلد كما هو (الملفات في جذر المستودع: `package.json`، `src/`، `server/`…). لا ترفع `node_modules` ولا `dist` ولا ملف `.env`.
2. **Railway:** New Project ← Deploy from GitHub repo ← اختر المستودع. سيقرأ `railway.json` ويشغّل `npm run build` ثم `npm start` تلقائيًا.
3. **Volume (مهم):** من الخدمة ← Settings ← Volumes ← Add Volume بمسار `/data`. بدونه تضيع العقارات والصور المضافة من اللوحة مع كل تحديث.
4. **Variables:**
   | المتغير | القيمة |
   |---|---|
   | `ADMIN_PASSWORD` | كلمة مرور اللوحة |
   | `DATA_DIR` | `/data` |
   | `COOKIE_SECURE` | `1` |
   | `TRUST_PROXY` | `1` |
5. **الدومين:** Settings ← Networking ← Generate Domain للتجربة، ثم Custom Domain لـ `alothman.com.sa` وعدّل سجلات DNS كما يطلب Railway (فقط بعد اعتماد الإطلاق).

**ملاحظات:**
- عند أول تشغيل تُنسخ العقارات والصور الحالية إلى الـ Volume، وبعدها تصير اللوحة هي المصدر. أي عقار يُضاف لاحقًا عبر GitHub لن يظهر إذا كان الـ Volume موجودًا، فأضف العقارات من اللوحة.
- النسخ الاحتياطي: Railway ← Volume ← Backups، أو نزّل مجلد `/data`.
- تغيير كلمة المرور: عدّل `ADMIN_PASSWORD` في Variables وسيُعاد تشغيل الموقع.

## قبل الإطلاق على النطاق

1. **نقل الصور والفيديو من الموقع القديم:** `npm run media:fetch` (يجب تشغيله قبل إيقاف ووردبريس). ينسخ صور العقارات وفيديو الواجهة إلى المشروع ويحدّث الروابط.
2. **الاستضافة:** Railway (انظر الخطوات أعلاه). ملف `public/_redirects` يحوّل روابط ووردبريس القديمة (‎/projects/‎، ‎/contact-us/‎ …) بتحويل 301.
3. **Google Search Console:** أضف النطاق وأرسل `https://alothman.com.sa/sitemap-index.xml`.
4. **Google Business Profile:** وحّد الاسم والعنوان والهاتف مع ما في الموقع (برج الغنيم، الدور السابع، مكتب 37، حي الشاطئ الغربي، الدمام). هذا أهم عامل للظهور في البحث المحلي والخرائط.
5. أكمل في `site.json`: رخصة فال، السجل التجاري، البريد، حسابات التواصل.

## هيكل الصفحات وSEO

| الرابط | المحتوى |
|---|---|
| `/` | الرئيسية: فيديو/مشهد افتتاحي، بحث، أنواع العقارات، عروض مختارة، المدن، الخدمات، نموذج طلب |
| `/properties/` | كل العروض مع بحث وتصفية (المدينة، الحي، النوع، بيع/إيجار، ترتيب) |
| `/properties/<slug>/` | صفحة العقار: معرض صور، التفاصيل، الموقع، واتساب/اتصال، حجز معاينة، عقارات مشابهة |
| `/khobar/` و`/dammam/` | صفحات المدن مع أنواع العقارات والأحياء والأسئلة الشائعة |
| `/khobar/al-hamra/` … | صفحات الأحياء (الحمراء، الصواري، الشعلة، ضاحية الملك فهد مستهدفة بمحتوى خاص) |
| `/khobar/apartments-for-sale/` … | صفحات «شقق للبيع في الخبر»، «فلل للإيجار في الدمام»… |
| `/services/`، `/about/`، `/contact/`، `/list-your-property/` | صفحات الشركة |

**قاعدة تجنب الصفحات الفارغة:** أي صفحة حي أو «نوع + مدينة» ليس فيها عروض ولا محتوى خاص تُعلَّم `noindex` وتُستبعد من خريطة الموقع تلقائيًا، وتدخل الفهرسة بمجرد إضافة أول عقار لها (المنطق في `src/lib/noindex.mjs`). لجعل حي «مستهدفًا»، أضف له `featured: true` ووصفًا فريدًا (`intro`) في `locations.json`.

**البيانات المنظمة:** RealEstateAgent (بيانات الشركة والعنوان)، WebSite + SearchAction، RealEstateListing لكل عقار، BreadcrumbList، FAQPage، ItemList، Service.

## التقنية

- `src/pages/` الصفحات، `src/components/` المكونات، `src/scripts/` الحركة (core: التمرير الناعم، الظهور، المؤشر، الأزرار المغناطيسية؛ home: المقدمة، تصغير الواجهة، الكلمات المضيئة، التمرير الأفقي لأنواع العقارات؛ skyline: المشهد المتحرك البديل للفيديو).
- الخطوط مستضافة داخل الموقع (Noto Kufi Arabic، IBM Plex Sans Arabic، Cormorant Garamond).
- الحركة تحترم إعداد «تقليل الحركة» في الجهاز، والفيديو لا يُحمَّل في وضع توفير البيانات.
